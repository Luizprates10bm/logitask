# LogiTask - TechFlow Solutions

Sistema de Gerenciamento de Tarefas Logísticas desenvolvido para otimização de fluxos de pátio e transporte de cargas.

## Tecnologias Utilizadas
* Java 17
* Spring Boot 3.2.2
* Spring Data JPA
* H2 Database (Ambiente de Testes)
* JUnit 5 (Testes Automatizados)
* GitHub Actions (Integração Contínua)
